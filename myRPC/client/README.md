# myRPC-client

Консольная утилита для удалённого выполнения bash-команд через протокол myRPC.

## Сборка

```bash
cd client
make all
# Бинарник: ../dist/myrpc-client
```

## Установка (deb-пакет)

```bash
make deb
sudo dpkg -i ../dist/myrpc-client_1.0.0_amd64.deb
```

## Использование

```
myrpc-client -c <команда> -h <хост> [ОПЦИИ]

Обязательные:
  -c, --command <cmd>   bash-команда для выполнения на сервере
  -h, --host    <ip>    IP-адрес или хостнейм сервера

Опции:
  -p, --port <port>     порт сервера (по умолчанию: 1234)
  -s, --stream          TCP-сокет (по умолчанию)
  -d, --dgram           UDP-сокет
      --help            показать справку
```

## Примеры

```bash
# Выполнить команду ls через TCP
myrpc-client -c "ls -la /tmp" -h 192.168.1.10 -p 1234 --stream

# Выполнить uptime через UDP
myrpc-client --command "uptime" --host 192.168.1.10 --dgram

# Получить список процессов
myrpc-client -c "ps aux" -h 192.168.1.10
```

## Протокол

Клиент отправляет JSON-запрос:
```json
{"login":"alice","command":"ls -la"}
```

Получает JSON-ответ:
```json
{"code":0,"result":"...вывод команды..."}
```

Код `0` — успех (вывод stdout), код `1` — ошибка (вывод stderr или описание).

## Идентификация пользователя

Клиент автоматически определяет логин текущего пользователя из переменных
среды `$USER` / `$LOGNAME`. Подмена логина не предусмотрена — это средство
аутентификации.
